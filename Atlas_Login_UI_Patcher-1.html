تحديث شاشة دخول الموسوعة السريرية

هذه الأداة تعدّل ملف index.html على جهازك مباشرة، ولا ترفع الملف إلى أي خادم أو ترسل محتواه عبر الإنترنت. وتشمل أيضًا إصلاح حفظ الجلسة، وإضافة زر تسجيل الخروج، وتسريع ظهور الموسوعة.

  1. نزّل أحدث ملف index.html من مستودع GitHub الخاص بالموسوعة إلى جهازك.
  2. اختر الملف من زر تحديد الملف أدناه.
  3. اضغط «تنفيذ التعديلات وتنزيل الملف»؛ سينتج ملف جديد باسم index-updated.html.
  4. استخدم الملف الجديد لاستبدال index.html في GitHub عندما تتمكن من الرفع.
  5. سيبقى الدخول محفوظًا عند تحديث الصفحة في التبويب نفسه، بينما يتطلب فتح تبويب جديد تسجيل الدخول مجددًا. يوجد أيضًا زر خروج واضح.
لم يتم اختيار ملف بعد.

لن تعدّل الأداة قاعدة البيانات أو محتوى الموسوعة. إذا لم تتطابق نسخة الملف مع النسخة المتوقعة، ستتوقف بدل إجراء تعديل غير مضمون.
